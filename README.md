Technologies Used
Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

Backend
- Python
- Django
Database
  MySQL
  APIs

Features
- Responsive design
- Product listing
- Product details
- User-friendly interface
- Backend API integration
- Database connectivity
- Data management using Django
- User authentication

Project Structure
- `frontend/` - Website frontend
- `backend/` - Django backend
- `templates/` - FIGMA templates
- `static/` - CSS, JavaScript and images
